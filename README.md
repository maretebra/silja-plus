# silja-plus
Sajt prodavnice Pet Shop „Šilja Plus“, Ralja.

## Najčešće komande (iz foldera `silja-plus`)

Ponovo napravi sve stranice posle izmene teksta, kataloga ili stila:

    ruby tools/generisi-stranice.rb

Unesi ili promeni najnižu i najvišu cenu po brendu (kartice „Kupujte prema brendu“):

    ruby tools/unesi-cene.rb

Za svaki brend pita cenu: Enter zadržava staru vrednost, `-` je briše. Na kraju sama ponovo pravi stranice.

Više detalja: `docs/sazetak-rada.md`.
